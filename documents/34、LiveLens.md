### 二、问题与动机

**核心问题**：直播电商中的销售额预测面临两大挑战——

1. **多模态复杂性**：直播内容包含视觉（面部表情、肢体动作）、听觉（语速、音调、音量）、文本（话术、促销语言）三重模态，传统依赖结构化数据或单模态的模型难以捕获这种复杂的交互。
2. **小样本数据稀疏**：大多数新兴主播仅有有限的历史数据，传统深度学习模型在这种数据受限场景下表现极差（𝑅² 为负，不如均值预测）。

**关键洞察**：并非直播的所有时刻都具有同等说服力。只有少数"高峰片段"（高语速 + 夸张表情 + 密集促销语）对购买转化起决定性作用。这一洞察源自行为心理学中的 **Peak-End Rule**（峰终定律）—— 人们倾向于基于体验中最情绪强烈的时刻（峰值）和最终印象来评价一段经历。

### 三、方法论

#### 3.1 整体框架（LiveLens）

LiveLens 包含三个核心组件：

1. **多模态特征提取** — 从视频、音频、文本提取专家指定的 16 维特征
2. **SCHA 稀疏内容感知高光聚合** — 核心创新模块，识别并加权高光片段
3. **Transformer 预测器** — 基于高光感知序列表示进行销售额回归

<img src="../../../../typora image/1-s2.0-S0957417426019378-gr1_lrg.jpg" alt="1-s2.0-S0957417426019378-gr1_lrg" style="zoom:33%;" />

1. 多模态直播**输入**：文本（直播弹幕、商品描述、主播字幕）、视频（直播画面）、音频（主播声音、背景音）、数值（实时观看人数、点赞数、商品价格、销量等）
2. 特征提取 (Feature Extraction)
3. 核心模块：**SCHA (模式识别与高亮检测)**
   * 它接收来自底部的多模态融合特征，进行深层的上下文计算。图中它在特征提取和预测模块之间，扮演了**“信息筛选器”**的角色。

4. 预测 (Prediction)
   - 经过 SCHA 模块处理后的有效特征，进入预测模块。
   - **网络结构**：**多头注意力 (Multi-headed Attention)** →→ **前馈网络 (Feed Forward)** →→ **Softmax**。

#### 3.2 专家访谈驱动的特征体系

通过 3 轮半结构化访谈 6 位领域专家（2 位头部主播、2 位专业主持人、1 位 MCN 营销总监、1 位平台专家），共识收敛出 **16 个跨模态指标**：

| 模态     | 特征                                                 | 量化方式                           |
| -------- | ---------------------------------------------------- | ---------------------------------- |
| **视觉** | 情绪表达                                             | 夸张表情占比（VGG-Face2）          |
|          | 动作幅度                                             | 上肢运动平均幅度（MoveNet）        |
|          | 场景构图                                             | 场景元素与产品属性对齐度（DINOv2） |
|          | 视频分辨率/帧率                                      | 直接计算                           |
|          | 主播外观                                             | 自动化面部吸引力评估 API           |
| **音频** | 语速                                                 | 与 7 词/秒 最优值的偏差            |
|          | 音调/音调范围                                        | 高音使用比例 + 变化范围            |
|          | 语调/音量                                            | 升调频率 / 平均音量                |
| **文本** | 娱乐价值 / 稀缺营销 / 折扣信息 / 个性化表达 / 互动性 | LLM + prompt engineering 提取      |

#### 3.3 SCHA — 核心创新算法

SCHA（Sparse Content-Aware Highlight Aggregation，稀疏内容感知高光聚合）是 LiveLens 框架的核心创新，灵感源自行为心理学中的 **Peak-End Rule（峰终定律）**（Fredrickson & Kahneman, 1993）：人们对一段经历的回忆和评价不取决于时间平均，而取决于**情绪最强烈的时刻（峰值）**和**最终印象**。在直播场景中，"终点"难以界定，因此 SCHA 聚焦于峰值——即那些**对购买转化起决定性作用的高表现力片段**。

现有方法将所有时间步同等对待（uniform weighting），导致两个问题：

- **信号稀释**：长时间直播中大部分帧贡献甚微，淹没了真正驱动转化的高光时刻
- **数据浪费**：在小样本场景下，模型需要大量数据才能从噪声中学习到有效模式，数据利用率极低

SCHA 的解决思路：**让模型聚焦于高光片段，抑制低信息区域**。

#### Step 1 — Highlight Scoring：高光片段打分

**目标**：给每个片段打一个"高光分数" $s_i ∈ [0, 1]$，表示该片段驱动购买行为的概率。

- 200 场独立直播，含精确到秒级别的交易日志
- 交易日志与多模态特征序列 ${x̂₁, x̂₂, …, x̂ₙ}$ 时间对齐
- **Label 规则**：交易强度 `τ_i > 1.5 × τ̄`（即该片段的交易强度超过全局均值 50%）→ 标记为 highlight（正样本）
- 阈值 1.5× 是经验选择，用于平衡精确率和召回率

#### Step 2 — Adaptive Pooling：自适应分组与动态权重

**分组**（阈值 θ = 0.6）：

```python
ℍ = {i | s_i > 0.6}   ← 高光组 (highlight)
ℕ = {i | s_i ≤ 0.6}   ← 普通组 (normal)
```

**动态权重函数 `f(K)`**

```python
f(K) = 1 + α · tanh((K − K₀) / σ)
```

| 参数         | 值         | 含义                    |
| :----------- | :--------- | :---------------------- |
| `K`          | MLP 预测值 | 当前视频的高光片段数    |
| `K₀ = 0.15n` | 先验期望   | 预期约 15% 的片段为高光 |
| `α = 0.5`    | 放大强度   | 高光嵌入最多放大 1.5×   |
| `σ = 5`      | 平滑度     | 控制过渡的陡峭程度      |

**关键设计要点**：
- MLP 是轻量的（3 层全连接 + ReLU + sigmoid），不会引入显著计算开销
- 训练数据的交易日志与实验主数据集**完全隔离**，避免信息泄露
- 动态权重 `f(K)` 确保高光片段过少时给予更大放大，过多时自动衰减

让 SCHA 能够根据不同直播的内容密度**自动调节聚焦强度**。

#### Step 3 — Highlight Reweighting：序列重构

对原始片段嵌入进行选择性重加权，构建最终的序列表示：

```python
𝐳_i = f(K) · x̂_i    if i ∈ ℍ  （高光片段 → 放大）
𝐳_i = x̂_i             if i ∈ ℕ  （普通片段 → 保持原样）
```

最终输出序列：`𝐙 = {𝐳₁, 𝐳₂, …, 𝐳ₙ} ∈ ℝⁿˣᵈ`

这个序列随后输入 **Transformer Encoder**（6 层 / 8 头 / d_model=512 / FFN 2048）进行时间建模和销售额回归。

#### 3.4 Transformer 预测器

- 架构：6 层 Transformer Encoder，8 注意力头，隐藏维 512，FFN 内维 2048
- 回归头：2 层全连接（hidden 256）→ 预测销售额 ŷ
- 损失：MSE + L2 正则（λ = 10⁻⁴）
- 优化器：Adam（η = 10⁻⁴，β₁ = 0.9，β₂ = 0.999），Dropout p = 0.1
- 端到端训练：梯度可同时流经 Transformer 和 SCHA 模块

### 四、实验评估

#### 4.1 数据集

| 指标      | 数值                             |
| --------- | -------------------------------- |
| 平台      | 抖音（TikTok 中国版）            |
| 时间范围  | 2024.10.23 – 2025.07.16          |
| 有效场次  | 2034 场（原始 2600 → 筛选后）    |
| 主播数    | 327 人（粉丝 10万–100万）        |
| 品类      | 服装 38%、化妆品 35%、农产品 27% |
| 平均时长  | 3240 秒（54 分钟）               |
| 训练/验证 | 8:2 划分，7 随机种子             |

#### 4.2 对比基线

| 方法                            | 核心策略                                                     |
| ------------------------------- | ------------------------------------------------------------ |
| **MEMF** (Xu et al., 2024a)     | 多实体多模态融合：BERT + ResNet50 + VideoMAE + Wav2Vec → Multimodal Transformer → CNN 预测 |
| **LiveRetro** (Wu et al., 2024) | 6 个多模态绝对值特征 + 15 个结构化特征 → XGBoost/RF/LSTM/MLP 自动选择 |

> ⚠️ 两种基线均未开源，作者根据论文描述进行了忠实复现。

#### 4.3 主要实验结果

| 训练样本         | 指标 | LiveLens     | MEMF     | LiveRetro | 提升     |
| ---------------- | ---- | ------------ | -------- | --------- | -------- |
| 2000（全量）     | 𝑅²   | **0.628**    | 0.413    | 负值      | +52%     |
|                  | MAE  | **0.0039**   | 0.026    | —         | −85%     |
|                  | RMSE | **0.0108**   | 0.027    | —         | −60%     |
| <500（小样本）   | 𝑅²   | **正值**     | 负值     | 负值      | 唯一可用 |
| <200（极小样本） | 𝑅²   | **稳定正值** | 完全失效 | 完全失效  | 唯一可用 |

**关键发现**：
- LiveLens 在所有数据规模下均优于基线，在小样本场景下优势尤为显著
- 当训练样本 < 500 时，MEMF 和 LiveRetro 出现负 𝑅²（不如直接预测均值），而 LiveLens 保持正值
- 跨品类（服装、农产品）一致性验证了框架的泛化能力

#### 4.4 消融实验

**融合策略对比**（Transformer + Combined modalities）：

| 融合策略     | MAE        | RMSE       | 𝑅²        |
| ------------ | ---------- | ---------- | --------- |
| Mean Pooling | 0.0118     | 0.0209     | 0.415     |
| CNN Fusion   | 0.0093     | 0.0195     | 0.441     |
| **SCHA**     | **0.0039** | **0.0108** | **0.628** |

**单模态贡献度**（SCHA + Transformer）：

| 模态       | MAE        | RMSE       | 𝑅²        |
| ---------- | ---------- | ---------- | --------- |
| 仅文本     | 0.0164     | 0.0275     | 0.205     |
| 仅视觉     | 0.0153     | 0.0270     | 0.295     |
| 仅音频     | 0.0141     | 0.0247     | 0.328     |
| 视觉+音频  | 0.0072     | 0.0139     | 0.512     |
| **三模态** | **0.0039** | **0.0108** | **0.628** |

**关键发现**：
- 音频模态最有效（单独使用 𝑅² = 0.328），验证了主播声音表现力的核心作用
- 文本单独效果最差（𝑅² = 0.205），但作为补充信息有价值
- 视觉+音频（双模态）已能取得 𝑅² = 0.512，三模态达到最佳
- 预测架构对比：Transformer > N-BEATS > CNN-LSTM，SCHA 在所有架构下均一致提升性能
- Wilcoxon signed-rank 检验：SCHA vs Mean/CNN 的改进在统计上显著（p < 0.05）

#### 4.5 特征相关性

| 最强相关特征             | Pearson r | Spearman ρ |
| ------------------------ | --------- | ---------- |
| 语速 (Speech Rate)       | 0.414     | **0.928**  |
| 情绪表达 (Emotion)       | 0.182     | **0.654**  |
| 场景构图 (Scene)         | 0.173     | 0.612      |
| 互动性 (Interaction)     | 0.145     | 0.573      |
| 娱乐价值 (Entertainment) | 0.148     | 0.527      |
| 分辨率 (Resolution)      | 0.123     | 0.521      |

→ Spearman（非线性单调关系）普遍高于 Pearson（线性关系），表明特征与销售的关联更多是**非线性**的，这也解释了为什么 Transformer 自注意力机制比传统回归更有效。

### 五、论文贡献总结

1. **LiveLens 框架**：首个将 Peak-End Rule 引入直播电商多模态预测的行为感知框架
2. **SCHA 算法**：数据驱动的高光识别 + 自适应池化 + 动态重加权，轻量且可解释
3. **专家特征体系**：通过系统化访谈构建 16 维多模态指标，弥合领域知识与数据驱动方法的鸿沟
4. **小样本性能突破**：在低资源场景下实现 +52% 𝑅²、−85% MAE、−60% RMSE 的显著提升
5. **可解释性**：通过 SHAP 值和可视化（Fig. 4 时序对齐图谱）直观展示哪些行为片段驱动了销售

---

### 六、局限与未来方向

- **专家规模有限**：仅 6 位专家参与访谈，扩大专家多样性可进一步丰富特征体系
- **平台单一**：目前仅在抖音平台验证，跨平台（如淘宝直播、快手）泛化有待验证
- **品类有限**：仅覆盖服装、化妆品、农产品三类
- **代码和数据**：承诺录用后开源代码，数据按请求提供

### 七、总结评价

这是一篇工程方法扎实的论文。其核心思想——"不是所有直播片段都同等重要"——简单但深刻，与行为心理学的 Peak-End Rule 结合得当。SCHA 算法的设计十分精巧：使用独立交易日志训练高光检测 MLP 避免了信息泄露，动态权重函数 `f(K)` 提供了自适应能力。实验设计严谨，7 随机种子 + Wilcoxon 检验保证了结论统计显著性。小样本场景下的压倒性优势（基线全部失效而 LiveLens 仍可用）是该方法最具说服力的卖点。不足之处在于专家样本偏小、跨平台验证缺失，但这些都在论文中坦诚讨论，并指明了未来方向。
