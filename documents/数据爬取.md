# 抖音直播多模态异构关系图数据爬取方案

根据您的 MEMF-GEF 架构设计，我为您梳理完整的**数据爬取需求清单**及**数据格式规范**，确保所有数据均来自抖音直播公开可见的数据流。

---

## 一、数据爬取总览

| 数据类别       | 对应实体/节点   | 爬取时机           | 数据源          |
| -------------- | --------------- | ------------------ | --------------- |
| 主播静态资料   | Anchor 实体     | 直播前/开播时      | 主播主页        |
| 商品信息       | Commodity 实体  | 直播前/开播时      | 商品橱窗/购物车 |
| 直播间静态信息 | Room 实体       | 开播时             | 直播间页面      |
| 弹幕流         | Audience 实体   | 直播中（实时流）   | WebSocket/轮询  |
| 实时互动指标   | Time-Slice 节点 | 直播中（定时采样） | 直播间API       |
| ~~礼物通知~~ ❌ | ~~Audience 实体~~ | ~~直播中（实时流）~~ | ~~直播间WebSocket~~ |
| 购买通知       | Audience 实体   | 直播中（实时流）   | 直播间WebSocket |
| 直播音视频     | Video/Audio     | 直播中（录播）     | RTMP/HLS流      |


## 二、各实体详细数据格式

### 2.1 Anchor 实体（主播）

**爬取来源**：主播个人主页 (`https://www.douyin.com/user/{sec_uid}`)

```json
{
  "anchor_id": "MS4wLjABAAAA1234567890",           // 主播唯一标识（sec_uid）
  "anchor_name": "张三带货",                        // 主播昵称
  "anchor_signature": "每晚8点直播，美妆护肤",       // 个人简介（文本）
  "follower_count": 1250000,                       // 粉丝数（数值特征）
  "total_likes": 35000000,                         // 获赞总数
  "total_videos": 520,                             // 作品数
  "avg_viewership": 8500,                          // 历史场均观看（需计算）
  "shop_score": 4.82,                              // 带货口碑分（0-5）
  "product_quality": 4.75,                         // 商品质量分
  "logistics_score": 4.68,                         // 物流服务分
  "service_attitude": 4.90,                        // 服务态度分
  "avatar_url": "https://p3.douyinpic.com/...",    // 头像图片URL（图像模态）
  "avatar_local_path": "./data/images/avatar_xxx.jpg",
  "crawl_time": "2026-08-18 19:30:00"
}
```

**说明**：历史场均观看需通过多场直播数据累计计算，可预先爬取该主播近30天的直播记录。

**爬取来源**：直播间商品橱窗/购物车列表 (`https://www.douyin.com/buyer/order/list` 或直播间API)

```json
{

  "commodity_name": "xx品牌 抗皱精华液 30ml",      // 商品标题（文本）
  "price": 299.00,                                 // 价格（元）
  "original_price": 599.00,                        // 原价
  "discount_rate": 0.50,                           // 折扣率
  "commission_rate": 0.15,                         // 佣金比例
  "sales_count": 8234,                             // 历史总销量
  "monthly_sales": 2341,                           // 月销量
  "good_rating": 98.5,                             // 好评率（%）
  "sku_count": 3,                                  // SKU数量
  "category": "美妆护肤",                          // 品类
  "sub_category": "精华",                          // 子品类
  "brand": "xx品牌",                               // 品牌
  "image_urls": [                                  // 商品图（图像模态）
    "https://p3.douyinpic.com/.../img1.jpg",
    "https://p3.douyinpic.com/.../img2.jpg"
  ],
  "image_local_paths": ["./data/images/comm_xxx_1.jpg", ...],
  "crawl_time": "2026-08-18 19:30:00"
}
```

### 2.4 Audience-Group 数据（观众群体）

**爬取来源**：弹幕流 + 互动事件流（WebSocket/轮询API）

> **关键设计**：不追踪个体用户身份，仅保留**匿名化行为模式**用于群体聚类。

#### 2.4.1 弹幕数据（核心）

```json
{
  "danmaku_id": "dk_20260818_193001_0001",
  "room_id": "7261234567890123456",
  "timestamp": "2026-08-18 19:30:01.234",          // 精确到毫秒
  "relative_time": 1.234,                          // 开播后相对秒数
  "user_nickname": "用户***1234",                  // 脱敏昵称（仅用于共现关联）
  "content": "这个精华好用吗？",                    // 弹幕文本（核心模态）
  "content_length": 7,                             // 文本长度
  "like_count": 3,                                 // 该弹幕获赞数
  "is_gift": false,                                // 是否附带礼物
  "is_purchase": false,                            // 是否购买通知
  "crawl_time": "2026-08-18 19:30:01"
}
```

**弹幕发送者昵称脱敏规则**：MD5(user_id + salt) 前8位 + "***" + 后4位，确保单场直播内可聚类但无法跨场次追踪。

#### 2.4.2 ~~礼物通知~~ ❌ 不可用（2026-09-28 定案）

> **该数据源已排除。** `WebcastGiftMessage` 不由 Web IM 推送通道承载 —— 抖音官方网页自身的
> WebSocket（同一端点族）同样收不到（150 秒 / 292 帧 / 14 种 method，礼物 = 0）；
> HTTP `/webcast/im/fetch/` 轮询 2737 条消息亦为 0。详见
> [特征体系与数据来源.md](特征体系与数据来源.md) §3.8。
>
> 下面保留原设计的字段结构，**仅作历史记录**，实际采集不会产出任何礼物事件。
> 若将来经 MITM 代理（PC 客户端）、HTTP 送礼榜接口或第三方平台补上礼物数据，可沿用该结构。

```json
{
  "gift_id": "gf_20260818_193005_0001",
  "room_id": "7261234567890123456",
  "timestamp": "2026-08-18 19:30:05.678",
  "relative_time": 5.678,
  "gift_sender": "用户***5678",                    // 脱敏昵称
  "gift_name": "超级跑车",                         // 礼物类型
  "gift_value": 299,                               // 礼物价值（抖币）
  "gift_count": 1,                                 // 数量
  "crawl_time": "2026-08-18 19:30:05"
}
```

#### 2.4.3 购买通知

```json
{
  "purchase_id": "pu_20260818_193012_0001",
  "room_id": "7261234567890123456",
  "timestamp": "2026-08-18 19:30:12.345",
  "relative_time": 12.345,
  "buyer_nickname": "用户***9012",                 // 脱敏昵称
  "commodity_id": "1234567890123456789",           // 购买的商品ID
  "commodity_name": "xx品牌 抗皱精华液 30ml",
  "quantity": 1,                                   // 购买数量
  "crawl_time": "2026-08-18 19:30:12"
}
```

**数据可行性说明**：抖音直播间会滚动显示"XXX 正在购买 [商品名]"，可通过DOM解析或API获取，但注意平台仅展示部分通知（非全量）。

#### 2.4.4 实时互动指标（用于Time-Slice）

```json
{
  "room_id": "7261234567890123456",
  "timestamp": "2026-08-18 19:30:00",
  "relative_time": 0,
  "online_viewers": 12345,                         // 在线观看数
  "total_likes": 456789,                           // 累计点赞数
  "likes_delta": 89,                               // 本分钟点赞增量
  "total_gifts": 234,                              // 累计礼物数（❌ 采不到，见 2.4.2，恒为 0）
  "gifts_delta": 5,                                // 本分钟礼物增量（❌ 同上，恒为 0）
  "total_purchases": 12,                           // 累计购买通知数
  "purchases_delta": 2,                            // 本分钟购买增量
  "danmaku_count": 45,                             // 本分钟弹幕数
  "crawl_time": "2026-08-18 19:30:00"
}
```

### 2.5 Time-Slice 时序数据

**爬取来源**：基于上述实时互动指标按时间窗口聚合（非直接爬取，而是后处理生成）

```json
{
  "slice_id": "ts_20260818_1930",
  "room_id": "7261234567890123456",
  "slice_index": 0,                                // 第几个切片（从0开始）
  "time_window_start": "2026-08-18 19:00:00",      // 窗口起始
  "time_window_end": "2026-08-18 19:15:00",        // 窗口结束（15分钟窗口）
  
  // 窗口内聚合数值
  "avg_viewers": 10234,                            // 平均在线观看
  "viewer_delta": 234,                             // 观看人数变化量
  "peak_viewers": 12345,                           // 峰值在线
  "total_likes_window": 45678,                     // 本窗口点赞数
  "total_gifts_window": 234,                       // 本窗口礼物数（❌ 采不到，见 2.4.2，恒为 0）
  "total_purchases_window": 45,                    // 本窗口购买通知数
  "danmaku_count_window": 890,                     // 本窗口弹幕数
  
  // 弹幕情感聚合
  "sentiment_mean": 0.23,                          // 平均情感得分（-1~1）
  "sentiment_std": 0.42,                           // 情感标准差
  "positive_ratio": 0.45,                          // 正向弹幕占比
  "negative_ratio": 0.22,                          // 负向弹幕占比
  "neutral_ratio": 0.33,                           // 中性弹幕占比
  
  // Top提及商品
  "top_mentioned_commodities": [
    {"commodity_id": "1234567890123456789", "mention_count": 56},
    {"commodity_id": "9876543210987654321", "mention_count": 34}
  ],
  
  "crawl_time": "2026-08-18 19:15:00"
}
```

### 2.6 直播音视频（可选模态）

**爬取来源**：抖音直播流 (RTMP/HLS)

> **说明**：如使用VideoMAE和Wav2Vec 2.0提取特征，需录制直播流。考虑存储成本，可仅**抽取关键帧**（每秒1帧）和**音频片段**（每30秒采样）。

```json
{
  "room_id": "7261234567890123456",
  "video_file_path": "./data/videos/live_xxx.mp4", // 录播文件路径（或流地址）
  "video_duration": 7200,                          // 视频时长（秒）
  "frame_interval": 1,                             // 抽帧间隔（秒）
  "total_frames": 7200,                            // 总帧数
  "audio_file_path": "./data/audio/live_xxx.wav",  // 音频文件路径
  "audio_sample_rate": 16000,                      // 采样率（Wav2Vec要求16kHz）
  "crawl_time": "2026-08-18 19:00:00"
}
```

**推荐方案**：使用 `ffmpeg` 实时抽取，每1秒保存一帧为JPEG，音频按16kHz/16bit保存为WAV，避免存储完整视频文件。


## 三、数据规模估算（单场直播）

| 数据类型                 | 预估规模       | 存储占用（原始） | 处理后            |
| ------------------------ | -------------- | ---------------- | ----------------- |
| 主播资料                 | 1条            | ~10 KB           | ~10 KB            |
| 商品信息                 | 20-50条        | ~200 KB          | ~200 KB           |
| 直播间信息               | 1条            | ~5 KB            | ~5 KB             |
| 弹幕（2-4小时）          | 5,000-20,000条 | ~5-20 MB         | 已含              |
| 实时指标采样（每分钟）   | 120-240条      | ~1 MB            | ~1 MB             |
| ~~礼物通知~~ ❌      | ~~200-1,000条~~  | ~~~200 KB-1 MB~~ | 采不到（见 2.4.2） |
| 购买通知                 | 100-500条      | ~100-500 KB      | 已含              |
| 图片（头像/封面/商品图） | 25-55张        | ~10-50 MB        | 特征提取后<1 MB   |
| 音视频（抽帧+音频）      | 7,200帧+音频   | ~2-5 GB          | 特征提取后<200 MB |

**建议存储策略**：
1. 原始音视频**不保存**，实时抽取帧+音频后丢弃原始流
2. 图片下载后压缩至224×224，提取特征后删除原图（或保留缩略图）
3. 结构化数据保存为Parquet格式（压缩比高）


## 四、爬取实现要点

### 4.1 技术栈建议

```python
# 推荐库
import httpx                    # 异步HTTP请求
import websocket                # WebSocket弹幕流
import aiohttp                  # 异步爬取
import ffmpeg-python            # 音视频处理
import numpy as np
import pandas as pd
```

### 4.2 核心难点与解决方案

| 难点                  | 解决方案                                                     |
| --------------------- | ------------------------------------------------------------ |
| **反爬虫机制**        | 使用手机UA + 代理池 + 滑块验证码破解（可考虑第三方API如`douyin_tool`） |
| **弹幕WebSocket协议** | 抖音WebSocket协议为Protobuf格式，需逆向`douyin` APP或使用开源库（如`PyThanos`） |
| **实时流录制**        | 使用`streamlink`或`ffmpeg`拉取HLS流，边下边抽帧              |
| **昵称脱敏**          | MD5(sender_id + salt) → 截取前8位+后4位，确保单场聚类能力    |
| **直播结束检测**      | 轮询直播间状态API，status变为`ended`时停止采集               |

### 4.3 数据采集时序

```
直播前（-30min）:
  └─ 爬取主播资料、商品橱窗、直播间静态信息

直播中（实时）:
  ├─ WebSocket订阅弹幕流（持续）
  ├─ 每1分钟采样互动指标（观看数/点赞/礼物/购买）
  ├─ 记录礼物通知和购买通知（实时）
  └─ 音视频抽帧（每秒1帧 + 音频分段）

直播结束后:
  ├─ 等待5分钟（确保所有数据落库）
  ├─ 生成Time-Slice切片数据
  ├─ 执行Audience-Group聚类（K-Means）
  └─ 保存完整样本
```
